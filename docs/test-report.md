## 2. 浏览器端到端测试

使用 headless Chrome 打开本地服务，执行以下流程：

1. 首页加载，页脚显示 `8 位联系人`，说明前端已从 `/api/contacts` 读取后端数据。
2. 打开记事簿，特别关心列表显示 6 位联系人。
3. 打开联系人详情，姓名、短码、分组、多个电话、邮箱、社交账号和地址正常显示。
4. 打开 Excel 导入/导出对话框。
5. 在界面新建联系人：姓名、两个电话号码、一个邮箱、收藏状态。
6. 等待自动保存后调用后端 API，确认联系人、两个电话和收藏状态已经写入 SQLite。
7. 刷新页面，页脚显示 `9 位联系人`，新联系人仍然可见，说明刷新后从后端重新读取。
8. 通过 API 删除测试联系人，恢复数据。
9. 浏览器控制台无错误。

结果：全部通过。
