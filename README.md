# VintageContacts · 纸间来电

按“复古红色转盘电话 + 纸质翻开记事簿”的设计实现的通讯录网站。纯 HTML / CSS / JavaScript，无构建步骤，不需要后端服务。

## 运行

安装 Node.js 20 或更高版本后，在本目录打开终端（无需安装依赖）：

```sh
node server.mjs
```

浏览器打开 http://127.0.0.1:4173/ 。不要直接双击 index.html，ES 模块需要 HTTP 服务。也可把 `dist/` 上传到支持静态网站的服务器。

## 已实现的体验

- 桌面首页：右侧红色电话、左下方小记事簿、浅色桌面与纸张纹理。
- 转盘：拖动旋转，把数字对到右下角指针，停留 1 秒录入；支持直接点击数字、连续重复数字、键盘访问数字按钮。气泡也可直接编辑、退格和清空。
- 电话状态：输入时听筒悬起；满 11 位后静置 2 秒，响铃动画持续 1 秒，再打开对应详情或带预填号码的新建页。更改号码会重新计时。网站不会实际拨打电话。
- 记事簿目录：左页特别关心、拨号与搜索打开次数合计前五的联系人，右页搜索、姓名字母索引与分组入口。搜索输入本身不计次，点击搜索结果打开才计一次。
- 联系人详情：左页备注，右页姓名、分组、多个电话、多个邮箱、多个社交账号和通讯地址。书签用于切换特别关心。姓名必填；电话号码允许 3–20 位数字，支持空格、括号、+ 和短横线格式化；跨联系人重复号码会阻止保存。
- 自动保存：编辑停顿 450 毫秒后保存，点击簿外或关闭时再次检查。空白页面不创建联系人，有未通过校验的内容时提示修正或放弃。刷新保留已保存数据。
- 分组：自定义分组、新建、删除、筛选；删除分组不会删除联系人，会归入未分组。不包含智能分组、我的名片、名片夹。
- Excel：右下角铅笔提供导入、模板下载与完整导出。导入先预览结果，错误行列出原因，确认后才写入。
- 响应式：窄屏记事簿变为上下纸页，全部字段保持可访问；默认静音，可用右上角音符打开合成音效。

## Excel 格式

使用第一张工作表，首行为列名：

| 姓名 | 分组 | 电话号码 | 电子邮箱 | 社交媒体账号 | 通讯地址 | 备注 | 特别关心 |
|---|---|---|---|---|---|---|---|
| 示例姓名 | 朋友 | 13800000000；13900000000 | hello@example.com | 微信:example；QQ:123456 | 城市和街道 | 一点小事 | 是 |

只有姓名是必需列。电话与邮箱用中英文分号或换行分隔。电话号码单元格请设为文本，以保留前导零；已经在 Excel 里丢失的零无法恢复。社交账号支持上述可读格式或本站导出的 JSON 数组。导出每位联系人占一行，所有单元格按文本写入，不执行公式。

按电话号码识别已有联系人：合并电话、邮箱、社交账号；导入的非空姓名、分组、地址和备注更新旧值；原有特别关心保留，导入“是”可以新增收藏。无电话的记录会作为新联系人。若同一行的号码命中不同联系人，跳过该行并提示手动核对。最多 5 MB / 5000 数据行。

## 数据边界

联系人保存在当前浏览器的 localStorage。没有云端数据库、登录账户或跨设备同步；部署网站不会同步联系人数据。清理浏览器、换浏览器或换域名都不会自动带上原来的通讯录，请先导出。首次打开提供 8 位虚构联系人；帮助窗口可移除未修改的示例。测试和演示时勿填真实个人隐私。

## 代码结构与验证

- `dist/index.html`：场景和页面入口，电话使用原创 SVG 图形。
- `dist/styles.css`：纸张、电话、转盘、记事簿与自适应布局。
- `dist/data.js`：联系人模型、校验、排序、Excel 映射和合并。
- `dist/app.js`：转盘状态、路由、表单、自动保存、Excel 文件操作。
- `tests/data.test.mjs`：冲突校验、导入错误处理、真实 xlsx 往返测试。

测试需 Node.js 20 或更高版本，无需安装依赖：

```sh
node --test tests/data.test.mjs
```

第三方库：`dist/vendor/xlsx.full.min.js` 为 SheetJS Community Edition 0.20.3，Apache-2.0 许可，许可见 `THIRD_PARTY_LICENSES.md`。库随站点打包，不依赖运行时 CDN。
